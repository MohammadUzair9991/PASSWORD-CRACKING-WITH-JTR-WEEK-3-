This repository documents my cybersecurity practical work on password security and auditing using John the Ripper (JTR).

The objective of this practical was to understand password security, password hash auditing, and the importance of creating strong passwords through an authorized laboratory environment.

This project was completed as part of my cybersecurity practical coursework.

🎯 Objectives

- Understand password security and hashing concepts.
- Learn about password auditing using John the Ripper.
- Understand the importance of password complexity.
- Explore how weak passwords can create security risks.
- Perform practical security testing in an authorized lab environment.
- Learn cybersecurity best practices for protecting credentials.

🧪 Practical Details

Practical: W3-PM1 — Password Cracking with JTR

Tool Used: John the Ripper

Operating System: Kali Linux

Environment: Authorized educational laboratory

Practical Activities

- Studied password hashing and authentication security.
- Explored John the Ripper and its role in password auditing.
- Conducted practical testing on laboratory-provided password samples.
- Observed password security weaknesses.
- Analyzed the importance of password complexity and secure credential management.

📚 Key Learning Outcomes

- Understanding password hashes and authentication mechanisms.
- Learning the purpose of password auditing tools.
- Understanding the security risks associated with weak passwords.
- Recognizing the importance of unique and complex passwords.
- Developing foundational knowledge of Linux cybersecurity tools.

🛡️ Security Recommendations

- Use long and unique passwords.
- Avoid common words and predictable patterns.
- Never reuse passwords across different accounts.
- Enable Multi-Factor Authentication (MFA).
- Use a trusted password manager.
- Store passwords using secure, salted hashing algorithms.
